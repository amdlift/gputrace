# Vendored bindgen output for header-free downstream builds

Trampolines need the exact `cu*` signatures, which we extract with `bindgen` from the CUDA driver headers. Running `bindgen` as part of the normal build would force every downstream builder (stock Ubuntu/Fedora) to install CUDA headers and `bindgen`, breaking the link-free portability we committed to. We instead run the `bindgen`-driven codegen as a **dev-time step and commit (vendor) its generated output** into the repo. Downstream builds then compile plain vendored Rust with no CUDA headers and no `bindgen`. The cost is that regenerating bindings is a deliberate maintainer action (re-run when targeting new driver versions) rather than automatic — an acceptable trade for a released artifact that builds anywhere the NVIDIA driver is present.
